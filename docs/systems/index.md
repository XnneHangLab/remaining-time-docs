# 每个选择，都与时间有关

《余时遗物》正在从一间可游玩的酒馆开始生长。这里介绍当前切片的玩法规则，也标出仍在展开的设计。

## 🪙 货币系统 {#currency}

### 用余时衡量一笔交易

生命余时也是交易的单位。买下商品会花费时间，出售物品和完成有报酬的工作则能补回余额。

目前可以与绯月买卖食品、饮料；余额不足时无法买入。帮工流程开启后，继续收拾餐桌可以获得余时报酬。只要能接近商人并与其交谈，餐饮打烊后也能交易。

**设计方向：** 让花费、劳动与日常选择产生联系。收入和物价仍在调整，商品的购买与持有也不代表其食用效果都已完成。

## ⏳ 时间流逝系统 {#time}

### 交谈时，世界也在继续

世界按一段段游戏时间推进，生命余时随之结算。普通对话不会让酒馆停下来：客人仍在用餐，服务员仍会忙碌。

你可以主动等待，也可以在获邀入住后到楼上睡眠。睡前会显示醒来时刻、时间消耗与剩余余额，确认后才执行。

切到后台、进入会暂停模拟的面板或长时间没有操作时，世界会暂停；回来后不会补扣离开的时长。

**设计方向：** 让等待和休息成为有分量的选择，同时减少离开屏幕带来的负担。时间流速与经济平衡仍在迭代。

## 🗝️ 收藏系统 {#collection}

### 先遇见线索，再认识遗物

普通物品和遗物各有自己的空间。遗物收藏有 31 个固定格位，每件遗物都有稳定的位置。

尚未获得的格位可以展示已经发现的线索及来源。真正获得遗物后，才能看到其图标、名称、故事和效果说明；找到线索本身不会直接赠送遗物。

**当前进度：** 收藏格位、线索展示与持有记录已接入。31 个格位是收藏规模，不代表 31 件遗物的完整剧情均已完成；效果说明也不代表所有特殊效果已经生效。

## 📜 任务系统 {#quests}

### 从一次小小的帮忙开始

任务可以分成前后相接的步骤，也可以让几个独立目标同时进行。符合条件时，新的目标会出现；已经发生的行动推动对应的进度。

酒馆里的一个例子是：帮忙收桌、领取赠饮，随后获得临时客房的邀请，再上楼查看床铺。不同事情可以拥有各自的谈话入口，让你选择眼下要处理的目标。

按 `T` 可以打开任务面板，查看当前需要做的事。

**设计方向：** 用任务组织人物之间的因果与承诺。当前重点是酒馆内的小流程，长篇主线仍在编排。

## 🎸 吉他指导练习 {#practice}

正式结识诗人后，在他可交谈和指导时借琴学习。当前课程为《Song Of Growth》，任务衔接见[酒馆旧版任务卡](/story-cards/tavern)。琴由诗人保管，借用不会增加背包物品。

| 操作 | 条件与方法 | 结果 |
| --- | --- | --- |
| 借琴 | 选择“能教我弹一会儿吗？” | 进入准备状态，诗人说明音区和跟弹方式。 |
| 听示范 | 准备阶段可先听同曲示范。 | 不计玩家命中或任务完成。 |
| 开始跟弹 | 按 E，准备2秒后开始约83.3秒练习，共49个短句起点。W高、A中、S低，判定窗口为前后180毫秒。 | 曲终命中至少30个短句起点才确认完成；提前达到门槛仍需弹至曲终。 |
| 错音或漏音 | 错按使短句首音跑调，其余音照常；漏按让该句留白。 | 伴奏和本轮练习继续。 |
| 重试／复习 | 曲终可重新开始，达标后也可复习。 | 每轮从头开始，已学进度保留；完成过的任务不重复完成。 |
| 结束指导 | 按 Esc，或诗人到离场时间。 | 归还借用乐器，保留已学进度；未完成的一轮不算达标。下次见面可重新开始。 |

## 🪑 场景交互 {#interaction}

| 目标 | 操作条件 | 行为与结果 |
| --- | --- | --- |
| 绯月的小铺 | 绯月在场可交谈；数量、店存及余时满足要求。 | 买入扣余时、减店存、加背包；卖出反向结算。餐饮打烊不单独禁止交易，详见[货币系统](#currency)。 |
| 餐桌与空凳 | 椅子可交互，整桌未被顾客占用。 | 坐下后记录位置与座位，起身返回原站位；无独立剧情奖励。 |
| 酒馆正门／营地帐篷 | 入口可通行。 | 出门进入营地，走入左侧帐篷门洞返回酒馆；经过门前不触发切换。 |
| 人物闲聊入口 | 绯月、莉奈可交谈；诗人另需已相识。 | 可打开话题或返回；当前自由闲聊为待接入的留白，无新剧情效果。 |

场景用途和人物日常安排见[世界背景](/story/background)，清桌、谢礼与客房许可的前后关系见[酒馆旧版任务卡](/story-cards/tavern)。

## 🎞️ 存档系统 {#saves}

### 把走过的时间，再交还给你

存档保存了可以回放的游玩过程。你可以重新观看人物的行动与自己的选择，也可以定位到回放范围内任意一个已记录的时刻，从那里重新开始游玩。

游戏会分段自动保存。刷新页面后，会恢复到最近成功保存的位置；尚未完成保存的进度不保证保留。

### 回看，再选择一次

1. 打开**设置 → 存档**，选择想查看的存档。
2. 点击**播放存档**，从该段开头开始回看。
3. 使用上一档、下一档和本档进度定位寻找想回到的时刻；支持暂停、单步与 1–8 倍速，播放结束会自动接下一档。
4. 在想接手的位置暂停，点击**从此处继续游戏**，重新作出选择。

你不必只从某一份存档的末尾继续，也可以在一段回放的中途接手。直接点击**加载存档**则会恢复所选存档的末尾位置。

::: warning 继续游玩会改变时间线
单纯观看不会修改进度，退出回放会回到观看前的游戏。

选择“从此处继续游戏”后，该位置之后的旧记录会被清除，新操作沿着保留的历史继续写入。加载较早存档同样会清除后续记录，并丢弃当前未保存的进度。当前不会同时保留两条分支。
:::

### 存档跟随当前浏览器与站点

当前存档保存在本机浏览器中，不会自动同步到其他设备。更换浏览器、域名或端口会使用另一份存储空间；清除网站数据会删除存档。

**设计方向：** 让每段经历可以重看，让已经记录的时刻成为新的起点。你可以先回顾发生过什么，再决定从哪里重新接手。
