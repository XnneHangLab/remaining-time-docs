# 世界背景 · 酒馆与人物

本页整理截至 **2026年9月15日**本地内容包 `npc-abilities-1` 中已呈现的背景，依据游戏提交 `58883cf17148de4e2fdeda88ae9da7e8a8079333`。人物关系、物件叙述和日常安排在这里集中介绍；具体发生的事件见[剧本任务卡](/story-cards/)，操作方法见[主要系统](/systems/)。

## 场景与用途 {#places}

| 地点 | 当前设定与用途 |
| --- | --- |
| 酒馆一楼 | 分为用餐区与接待区，绯月在柜台经营小铺，莉奈接待用餐客人。 |
| 演奏花毯 | 位于靠隔墙下方，是绯月为往来艺人预留的演奏角落。 |
| 阁楼客房 | 从柜台右侧木楼梯进入，窗边有书桌，床靠右墙。原本为临时帮工准备，绯月在首次帮工后邀请玩家免费暂住。 |
| 林间营地 | 与酒馆正门连接；左侧帐篷门洞是返回入口。目前可探索和通行，室外人物活动尚未接入。 |
| 赌坊 | 由绯月与莉奈的线索提及，老鬼在那里保管遗物；当前尚未开放该场景。 |

## 人物与关系 {#people}

| 人物 | 身份与日常职责 | 已呈现的关系与背景 |
| --- | --- | --- |
| 绯月 | 酒馆老板，经营食品饮料小铺，安排帮工与临时住宿。 | 与吟游诗人相识已久，为艺人留出演奏位置，惯常请老朋友喝余晖陈酿。 |
| 莉奈 | 酒馆服务员，负责迎客、送餐和清桌。 | 与绯月分工经营酒馆；送酒时听过老鬼关于遗物赌注的说法。 |
| 吟游诗人 | 四处旅行，以唱歌、弹琴和故事结识各地人，也能指导玩家练琴。 | 当前曲子学自渡口船夫；讲述春船起航时在船头系干花、盼旅人平安的习俗。山歌与海边故事只是对白中的后续邀约。 |
| 老鬼 | 赌坊常客，当前仅由消息提及。 | 随身保管一件遗物，不愿出售，只肯把它用作赌注。 |
| 来往客人 | 入店、点餐、用餐后离开，部分人会停下来听演出。 | 有人赶路，有人惦记诗人上次讲的雾岭故事，有人想问海那边的见闻。离店后保留身份，后续去向与再次来访尚未安排。 |

绯月解释，艺人不向她领取演出工钱，客人可以自愿打赏；演出也让客人多坐一会儿、带朋友再来，给店里带来生意与口碑。请酒习惯由对白呈现，当前没有玩家送酒任务。

## 每日作息 {#schedule}

以下是当前内容安排的行动起点，路线受阻和服务收尾可能延迟实际到达。人物每日往返，已经完成的相识、首演、任务和学习进度保留。

| 时刻 | 人物／场景 | 日常安排 |
| --- | --- | --- |
| 00:30 | 绯月 | 开始离场，暂停交谈、交易与谢礼领取。 |
| 10:00 | 绯月 | 返回柜台，到位后可交谈和交易。 |
| 13:00 | 莉奈 | 返回服务区，到位后可交谈，营业时接待客人。 |
| 17:00 | 酒馆 | 开始迎客，另需莉奈在岗。 |
| 18:30 | 诗人 | 首次进场或每日返回花毯；未完成的首演在条件满足后开始或继续。 |
| 21:00 | 诗人 | 开始离场，结束当下的交谈或指导。 |
| 22:00 | 酒馆 | 停止迎接新的用餐客人，已有客人继续用餐、离开，工作人员收尾。 |
| 23:00起 | 莉奈 | 完成已接待客人的服务后离场。 |

世界时间如何推进、等待与睡眠如何结算，见[时间系统](/systems/#time)。剧情节点的具体时机与额外条件仍写在对应[任务卡](/story-cards/)中。

食品饮料尚未接入食用效果，三件预置遗物不是任务奖励，特殊效果尚未实现。交易规则见[货币系统](/systems/#currency)，线索与实物的关系见[收藏系统](/systems/#collection)。
