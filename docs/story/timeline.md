# 剧本时间线

本页整理截至 **2026 年 9 月 14 日**已合入的酒馆剧本，包含当前任务的前置、对白概要、可选分支与结果。场景范围是一楼酒馆和二楼临时客房。

故事从第一天 **18:00** 开始。帮工与结识诗人可以交错进行，打听遗物也有独立入口；下面的章节顺序便于阅读，并不要求玩家依次完成所有事情。

## 故事路线一览

| 故事线 | 起点 | 推进顺序 | 当前结果 |
| --- | --- | --- | --- |
| 熟悉移动 | 初到酒馆 | 向上、下、左、右走动 | 完成移动教学，可自行探索 |
| 老板娘的招呼 | 有客人离席，留下待清理的餐具 | 询问绯月 → 答应帮忙 → 清理一桌 → 回柜台领取谢礼 | 获得柚光汽水、阁楼暂住许可，并开启按桌计酬 |
| 一个落脚点 | 领取首次帮工谢礼 | 上二楼 → 到床边查看休息安排 | 找到客房；是否睡觉、睡多久由玩家决定 |
| 酒馆里的老朋友 | 诗人的首演结束 | 向绯月打听 → 接受引介 → 到花毯旁自我介绍 | 正式结识吟游诗人 |
| 弦上的第一步 | 与诗人正式相识 | 借琴 → 听示范或直接练习 → 完成一轮达标的跟弹 | 保留学习进度，归还乐器，以后可复习 |
| 赌坊遗物的消息 | 绯月或莉奈可交谈时 | 分别向两人打听，顺序不限 | 收集关于老鬼、遗物所在地和赌注的两条线索 |

任务面板只揭示当前已知目标。各阶段的背景会回顾从起因到当下的经过；任务完成后保留总结。

## 第一天 18:00 · 走进酒馆 {#arrival}

你从一楼正门进入。酒馆里有餐桌与圆凳，柜台在接待区，右侧靠墙的木楼梯通往二楼；靠隔墙下方的花毯是留给旅行艺人的演奏角落。绯月在柜台后，莉奈忙着迎客、送餐和收桌。

开局拥有 **120 小时余时**，当前目标是“熟悉移动”。向四个方向走过后，移动教学完成；探索、交谈和其他故事线不必等教学结束才开始。

### 柜台前的第一次招呼

第一次与绯月交谈，她介绍自己：

> 欢迎，我叫绯月，是这里的老板。赶路辛苦了。我们每天下午五点迎客，晚上十点打烊。

再次来访时，她会邀请你歇一歇、找个舒服的位置，或问你想喝一杯还是聊几句。忙碌时，她提到莉奈正被几桌客人牵住；打烊后，她会说店里安静下来，仍可以聊聊或买东西。

这些招呼建立了你与酒馆的初次接触。具体事情放在各自的话题里，玩家可以先购物、打听消息，也可以暂时离开。

### 认识莉奈

莉奈会招呼你：

> 晚上好。刚出炉的点心很香，找张空桌坐坐吧。

她的回应随帮工进度变化：答应帮忙后，她说明只需收一张客人离席后的桌子；桌子收好后，她道谢并提醒绯月在柜台等你；领取谢礼后，她说明往后收桌会直接记账，也劝你别一直忙，找个位置休息。

## 客人离席后 · 老板娘的招呼 {#help}

**触发：** 酒馆出现至少一张留有餐具、尚未清理的桌子。

“老板娘的招呼”出现，提示你到柜台问问绯月。她解释：刚走的那桌还没收，莉奈又要招呼新来的客人，希望你搭把手，并答应收好后请你喝瓶汽水。

### 答应，或先去做别的事

选择“好，我帮莉奈收一张桌子”，才正式接下帮忙的事情。玩家也可以退出话题，继续探索或处理别的事，之后再回来答应。

接受后，等客人离席，走到留下餐具的桌边按 E 清理。当前清理一桌需要约三秒，可以中途停下；收好一桌后，任务提示你回柜台领取谢礼。

### 一瓶汽水，一份邀请

绯月感谢你收得利落，交付说好的 **柚光汽水**，也说明店里最近来往的客人多，正缺个搭手的人。阁楼有间原本留给临时帮工的小房间：

> 你要是还没定落脚处，也愿意有空帮忙收收桌，可以先住在那里，不收房费。收桌的报酬另算，每收一桌结五分钟余时。

确认收下谢礼后，汽水进入背包，客房开放，后续收桌开始按 **每桌五分钟余时**计酬。首次帮工的谢礼是汽水；持续帮工的报酬从后续餐桌开始。

任务在这里完成。留下多久、是否立刻上楼，以及之后要不要继续收桌，都由玩家自己安排。

## 获邀之后 · 一个落脚点 {#room}

**前置：** 已领取首次帮工谢礼，并得到绯月的暂住邀请。

“一个落脚点”引导你从柜台右侧、靠墙的木楼梯上楼。尚未获得许可时，楼梯会提示客房还没安排好，应先去柜台问绯月。

上楼后是安静的临时客房：窗边有书桌，床靠右墙，楼下的杯碟声隔着木地板变轻了。走到床边查看，可以读到：

> 干净的床单带着晒过的气味。窗边很安静，楼下的声音隔着木地板变得很轻。这间房暂时借给你住，不收房费；睡眠仍会消耗经过的余时。

**查看床边的休息安排就会完成任务。** 任务总结记录你找到了房间、了解了安排；真正入睡是之后的可选行动。

选择“睡觉”后，可以在一至二十四小时之间选择，默认八小时。确认前显示醒来时间与余时消耗；取消则留在床边。醒来仍在客房，楼下的人物会按经过的时间生活、营业与休息。木楼梯可以带你回到一楼。

这条线可以在听诗人演奏之前，也可以在学琴之后推进。

## 第一天 18:30 起 · 花毯上的首演 {#performance}

**触发：** 到达诗人首次来访的时刻，他从正门进场，走到花毯上。入口或路线上有人挡住时会等待或重新找路；到位后，玩家也在一楼，首演才开始。

老人向柜台打招呼：

> 绯月，老位置还给我留着呢。晚上好，各位，带了首渡口的新曲子。

当前演出采用《Song Of Growth》的木吉他编配，约九十三秒，包含开场与曲终的回应。玩家可以继续在酒馆走动，莉奈也照常服务。

### 客人如何回应

听众对这位旅行艺人各有期待：

| 听众 | 演奏中的反应 | 曲终与离席 |
| --- | --- | --- |
| 赶路的人 | 认出老人又来了，但今天还得赶路 | 轻轻拍手，说下次再听，随后离开 |
| 记得旧故事的人 | 想起上回讲到雾岭封雪，惦记那边是否开春 | 道谢，觉得心里安静多了，愿意打赏一分钟余时 |
| 想听远方见闻的人 | 想先听完这段，再问海那边的故事 | 鼓掌，愿意送上两分钟余时 |

有些用餐结束的客人会到花毯前停留片刻；能否听到具体回应，取决于谁在场、听了多久和站位情况。客人打赏归诗人所有。

没有听众接话时，绯月会回应老朋友，说余晖陈酿给他留着，也赞叹这把琴又让店里热闹起来。曲终，诗人感谢大家与绯月的酒，邀请想听路上故事的人来毯子边聊聊。

### 演出如何接上后续

演出结束后，才出现“酒馆里的老朋友”。演奏期间不能与诗人交谈；“静音”旁的“跳过”可以直接结束首演，正常接上后续任务。

离开一楼、主动等待或睡觉会保留尚未结束的首演进度；回到一楼、诗人在场时继续。首演只完成一次，人物以后的每日往返会保留这段经历。

## 曲声落下 · 酒馆里的老朋友 {#meet-bard}

绯月向老人熟稔地点头，引起了你的注意。任务先让你回柜台询问：“刚刚在演奏的那个老头是谁，老板你好像认识他？”

### 绯月的介绍

她说老人是自己的老朋友，一位吟游诗人。这些旅行艺人会弹会唱，也会讲故事，有的还会写诗、变小戏法。他们走南闯北，带回曲子、风土和消息。

花毯是绯月专门为他们留的演奏位置。他们不向她讨工钱，客人愿意打赏多少都随意；艺人的到来也让客人多坐一会儿、带朋友再来，给酒馆带来生意与口碑。她每回都会请老朋友喝一杯余晖陈酿。

听过介绍后，确认愿意去问好，绯月才正式为你引介。若一时没找到老人，还可以再问她位置，她会指向靠隔墙下方的花毯。

### 到花毯旁自我介绍

在完成绯月引介前，演出后接近老人，只能看到他收拢琴弦、向柜台致意，感觉两人认识很久。引介之后，老人会说：

> 绯月说你是新来的旅人。很高兴认识你。我沿途唱歌、弹琴，也替人记下故事；会的手艺多些，路就能走得远些。

选择自我介绍，双方正式相识，“酒馆里的老朋友”完成，并开启学琴的事情。如果老人已经离场，可以等他回来继续，不必重新听一次首演。

### 渡口的曲子

相识后，他会讲述刚才那支调子的来历：渡口的人在第一条春船起航时，把干花系在船头，盼出门的人平安回来。他在渡口住了三晚，才向老船夫学全最后一段。

老人问你下次想听山里的歌，还是海边的故事。这是当前对白留下的邀约。

## 相识之后 · 弦上的第一步 {#practice}

**前置：** 已正式认识诗人，他仍在酒馆且可以交谈。

“弦上的第一步”提示你向他请教。选择“能教我弹一会儿吗？”，老人暂时把琴借给你，自己保持和弦伴奏：

> 跟着和弦的起伏来。金线经过短句起点时拨一下，一小段旋律就会随你响起：W 高音、A 中音、S 低音。错一个音也没关系，后面的音照常接上。

可以先听老师示范，也可以直接按 E 开始。准备两秒后，沿五条谱线滚动的提示经过金线；W、A、S 分别对应高中低音区，一次按键带出一个短句。

当前是一首约八十三秒的完整练习，有四十九个短句起点。跟上其中三十个，就能完成这一轮学习。按错只让短句第一个音跑调，后续音照常接上；漏按让这一句留白，伴奏仍继续。

曲终达标后，任务记录你在诗人指导下完成了第一次整曲跟弹。可以反复复习；未达标也可以重试。按 Esc 结束指导，乐器归还诗人。

**学习进度会保留，乐器仍由诗人保管。** 到他的离场时间，指导会中断，下次见面可重新开始一轮。

## 交谈的空隙 · 遗物的两条消息 {#relic-clues}

这条支线不需要先完成帮工、客房或学琴。只要对应人物在场且能够交谈，就能询问；两条消息可以任意顺序获得。

### 从绯月那里问到所在地

向绯月问“附近有人收藏遗物吗？”，她提供一条消息：

> 赌坊里有个被叫作老鬼的常客，随身保管着一件遗物。想找那件东西，可以先去找他。

这条消息记入遗物收藏中的线索，并保留绯月作为来源。

### 从莉奈那里问到交换条件

向莉奈问“你听说过赌坊里的那件遗物吗？”，她补充：

> 莉奈送酒时听老鬼说过，他不肯收钱卖掉那件遗物，只愿意把它当作赌注。

这条消息与绯月的线索归在同一件尚未得到的遗物下。取得线索不会得到实物，每条线索只收集一次。

这段故事目前停在“知道去哪里找、对方愿意用什么方式拿出遗物”。赌坊场景、与老鬼见面和下注取得遗物的情节尚未开放。

## 营业中的片段 · 买卖、座位与物件 {#daily-life}

这些内容可以穿插在任务之间，构成酒馆里的日常。

### 绯月的小铺

与绯月交谈时，可以查看她卖的六种食品饮料。买卖使用生命余时，物品进入普通背包；即使过了迎客时段，只要她仍在场并能交谈，交易也可以继续。

| 物品 | 物件叙述 |
| --- | --- |
| 余晖陈酿 | 琥珀色酒液封在圆肚瓶中，绯月会把最后一杯留给愿意听完故事的客人；她也在对白中提到请诗人喝这款酒。 |
| 夜炉巧克力圈 | 刚出炉的面圈裹着厚巧克力和彩糖，纸袋还没打开，甜香就先跑出来。 |
| 柚光汽水 | 浅金色气泡、手绘柚子瓶贴，是酒馆这一季的新口味，也是首次帮工的谢礼。 |
| 炉火可乐 | 红纸环标、深褐色玻璃瓶，熟客点它时通常还要一杯冰。 |
| 青麦啤酒 | 翠绿罐身印着金色麦穗，被绯月整齐码在柜台下。 |
| 雾岭山泉 | 蓝白纸标画着远山，是长途赶路后常受欢迎的饮品。 |

当前可以获得和买卖这些物品，食用效果尚未接入。请诗人喝酒的习惯由对白呈现，没有额外的玩家送酒任务。

### 来客与空凳

随机来客会进店、找座位、点餐、用餐、离席；莉奈往返服务，也会清理餐具。玩家可以坐在可用的空凳上休息，再起身继续活动；有人用餐的整张桌子会保留给那组客人。

### 收藏中的物件叙述

当前开发版本预置了三件收藏展示物，它们不是通过以上任务获得的奖励：

- **回声怀表：** 表针停在无人认领的时刻，贴近表壳仍能听见齿轮缓慢走动。
- **航迹罗盘：** 曾用于共居区的维护通道，盘面刻着手工路线，终点被仔细磨去。
- **折光胸针：** 紫色晶片把灯光折成色带，背面的针扣反复修补，显然被主人珍惜了很久。

三件物品的共鸣均未激活，特殊效果尚待确认；这些文字目前提供的是物件背景。

## 夜深与次日 · 人物继续生活 {#night}

世界时钟与人物作息贯穿所有故事线。交谈时，酒馆的其他活动也继续；等待与睡眠可以让时间向前，任务和相识进度会保留。

| 时刻 | 酒馆中的变化 |
| --- | --- |
| 21:00 | 吟游诗人开始离场，结束当下的交谈或指导。 |
| 22:00 | 酒馆停止迎接新的用餐客人，已有客人继续用餐、离开，工作人员收尾。 |
| 23:00 起 | 莉奈准备离场，先完成已接待客人的服务。她打烊后的招呼会提到剩下的收尾慢慢来。 |
| 次日 00:30 | 绯月开始离场。 |
| 次日 10:00 | 绯月返回柜台。 |
| 次日 13:00 | 莉奈返回服务区。 |
| 次日 17:00 | 酒馆再次进入迎客时段。 |
| 次日 18:30 | 诗人返回花毯旁，可继续尚未完成的相识、交谈与练习；未结束的首演会在条件满足时续上。 |

这些时间是人物开始行动的时刻；走路、堵路和服务收尾可能让实际到达或离开稍晚。每日作息重复，已经完成的首演、首次相识和任务不会因此重置。

## 当前故事停在哪里 {#current-scope}

目前五个任务分别围绕移动、首次帮工、阁楼暂住、结识诗人和借琴练习展开，遗物支线推进到两条消息的收集。玩家可以在这些相遇之外持续帮工、买卖、休息和复习曲子。

绯月、莉奈与诗人的自由闲聊入口仍是待接入的留白；山里的歌、海边的故事尚未展开为新的分支。乐器传承、赌坊和老鬼的后续也还没有成为可玩的任务。

新的剧情需要开启新的时间线加载；已有存档保留它开始时的剧情内容。近期改动见 [Daily Build 更新](/daily-build/)，时间、任务与存档的玩家规则见[主要系统](/systems/)。
