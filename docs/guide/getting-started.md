# 关于文档

这里是 remaining-time 的公开文档站。内容随开发进度整理，分为以下四类：

- **daily build 更新**：每个构建版本中实际发生的变化。
- **剧本时间线**：按时间与事件阶段阅读故事，了解人物、前后条件和分支结果。
- **编剧 Agent 能力与 Skill**：能编排哪些行为、如何使用 Skill，以及当前能力边界。
- **主要系统**：货币、时间流逝、收藏和任务系统的设计目的与玩法规则。

## 内容反馈

发现文档问题，可以在[文档仓库](https://github.com/XnneHangLab/remaining-time-docs/issues)反馈，也可以通过页面上的“编辑本页”提交修改。

## 参与编写

文档使用 Markdown 编写。修改通过 Pull Request 合入文档仓库的 `dev` 分支后发布。
