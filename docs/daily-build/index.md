### 本地试做 · 尚未合入

404 新增黑框室内候选：保留北侧背墙和独立家具，将侧墙与前墙改为房间边界，门口留出通道。墙沿加入细描边、灰绿截面与柔和阴影，出口地板逐渐融入黑色；同时调整画布底色和相机下缘，让角色靠近出口时走向屏幕底部。

围墙与黑框两套素材均保留，当前仍使用围墙版。黑框方案及配套相机调整尚未合入，视觉与通行手感仍在比较验收中。

**验证范围**：房间包与 NPC 对齐的 3 项针对性检查、自动存档与记录轮转的 3 项针对性检查通过；黑框试做另做了边界和出口往返检查。自动检查不代替全地图实机验收，本轮未运行完整测试或构建。

**存档提示**：体验新的房间内容需开启新时间线；旧时间线继续使用嵌入的场景配置。地图尺寸、入口和碰撞的后续调整也需在新时间线中体验。
