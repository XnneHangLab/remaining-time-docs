# Daily Build 更新

每次回到酒馆，都有一点新的变化。

这里按开发分支当日合入的内容整理，日期采用 UTC。目前提供每日开发更新记录，尚未提供独立 Release 下载包。

## 2026.09.15 · 推开门，到林间走走 {#day-2026-09-15}

### 酒馆之外，有了可以散步的地方

从酒馆出口走出去，可以来到林间营地。树木、帐篷与水流铺开在视野里，营火、水花和风车也有了动态表现。

- **出去走走，也能原路回来。** 酒馆与室外已经连通；走进左侧帐篷的门洞，就能回到熟悉的室内。
- **门前可以自由走动。** 在帐篷门口经过或停留不会切换场景，进入门洞才会触发返回。
- **旅程留在同一条时间线。** 室内外通行沿用现有时间、存档与回放流程。目前室外开放探索与通行，人物的室外活动仍待接入。

### 人物身份与活动分开整理

人物开始或结束一段活动时，保留自己的身份。动态顾客离店后仍留下人物记录，之后的去向与再次来访尚未安排。

商店、服务、演出和教学配置现在归属各自的人物；坐下时的座位绑定归入活动状态。已有的交易、服务和学琴规则沿用，这次主要整理人物与玩法的归属，方便继续编排内容。

### 地图与剧情可以分别编辑

地图的地形、碰撞、图层和环境动画统一用 JSON 配置；场景负责人物与物件的摆放和连接，剧本负责对白、条件与任务。后续调整地图和人物内容时，可以更清楚地找到对应位置。

具体职责与当前边界见[世界架构说明](/architecture/world-model-2026-09-15)。

::: tip 体验本次更新
室外场景和新的 NPC 配置需要从存档 0 开启新时间线。已有时间线继续使用原内容与规则，旧存档仍可恢复和回放。
:::

## 2026.09.14 · 跟着诗人，拨响第一句 {#day-2026-09-14}

### 演出之后，借琴练一会儿

正式结识吟游诗人后，可以在他演出结束、还有空闲时向他请教。琴暂时借给你，练习结束后归还；学会的进度会保留，下次见面可以继续复习。

- **用三个键跟上旋律。** W、A、S 分别对应高、中、低音区。提示沿五条金色谱线滚动，经过判定线时拨一下，就能带出一小段旋律。
- **和弦陪着你向前。** 当前练习曲为《Song Of Growth》，使用木吉他音色。老师示范、玩家练习和首演使用同一首曲子的编配；和弦有重拍与渐强起伏，后段音区抬高，结尾渐弱。
- **错一个音，继续下一句。** 按错只影响短句的第一个音，后面的音仍按原谱接上；漏按会让这一句留白，伴奏继续。跟上足够的短句，就能完成这一轮练习。
- **可以先听，也可以再来。** 按 E 开始，Esc 结束；准备时可听老师示范，曲终可以重试。首演的“静音”旁也增加了“跳过”，方便直接接上演出后的剧情。

“弦上的第一步”会记录这次借琴与练习的经过。诗人现在会留到 **21:00** 再开始离场，给演出后的交谈和指导留出时间。

### 人物有了各自的作息

绯月、莉奈和吟游诗人会按自己的时间进出酒馆。人物休息时会结束交谈，返回后再继续相见；莉奈会先完成已经接待客人的服务。门口或路线上有人挡住时，他们会等待或绕行，实际到达可能稍晚。

| 人物 | 返回酒馆 | 开始离场 |
| --- | --- | --- |
| 绯月 | 10:00 | 次日 00:30 |
| 莉奈 | 13:00 | 23:00 |
| 吟游诗人 | 18:30 | 21:00 |

等待与睡眠也统一为 **1–24 小时的滑条**：等待默认一小时，睡眠默认八小时。确认前可以看到结束时刻、余时消耗和剩余余额。

### 任务记住来龙去脉

任务面板会逐步揭示当前目标，并完整回顾从起因到当前阶段的经历。即使中途略过对白，也能回来查看为什么接下这件事、已经做过什么、接下来要去哪里。

帮工、结识诗人、客房与学琴等任务完成后会保留总结。新任务、进度变化和任务完成，也会在左侧出现提示。

### 用键盘把话聊完

对话中用 **W/S 或 ↑/↓** 选择选项，**E** 确认，**Esc** 离开。当前选项会高亮并自动滚入视野，打开对话或切换话题后默认选中第一项；鼠标与 Tab/Enter 操作照常可用。

::: tip 体验本次更新
新的作息、课程和任务内容需要开启新的时间线。已有时间线会保留开始时的剧情内容。
:::

## 2026.09.12 · 听一首歌，找一个落脚点 {#day-2026-09-12}

### 人物走进故事

- **酒馆有了吟游诗人。** 经绯月介绍、与他相识后，可以围绕不同话题交谈；到了演出时段，他会在专属区域演奏，周围客人也会作出反应。
- **招呼更贴近当下。** 绯月会区分初次见面和再次来访，并根据营业时段与忙碌程度回应。
- **先选话题，再聊事情。** 日常问候与不同任务的谈话入口分开，方便选择此刻想聊的内容。
- **对白出现在角色身边。** 场景内的对白气泡配合可滚动的选项，让交谈留在酒馆之中；同时扩大了游戏画面的展示空间。

### 一张餐桌，一间阁楼

帮忙清理第一张餐桌、领取赠饮后，绯月会邀请你暂住楼上的临时客房。“一个落脚点”引导你上楼查看床铺。

床铺提供睡八小时或睡到次日 16:00 的选择。确认前可以看到醒来时间与生命消耗；这间临时客房免收房费，睡眠仍会消耗经过的时间。

### 交互更顺手

- 只要能找到商人并正常交谈，就能买卖商品；打烊后也可以交易。
- 靠近可交互的人物和物件时，会出现白色轮廓提示。
- 酒馆服务员可以使用多个柜台交接位置，减少单个位置被挡住时的停顿。

::: tip 体验新增剧情
已有时间线会保留开始时的剧情内容。想体验这批新对白与任务，请开启新的时间线。
:::

## 2026.09.11 · 时间开始流动，遗物有了位置 {#day-2026-09-11}

### 酒馆有自己的节奏

世界时间开始按段推进，生命余时随时间结算；普通交谈期间，人物活动与世界时钟也会继续。主动等待让你更快抵达下一个时刻，后台与闲置暂停则保留离开时的进度。

### 给遗物留一个位置

- 普通背包与遗物收藏分开，分别通过 `1`、`2` 或界面入口打开。
- 收藏使用 31 个固定格位，获得顺序不会改变遗物的位置。
- 尚未获得的遗物也能查看已经发现的线索与来源；获得后揭示名称、故事和效果说明。
- 线索与遗物分别收集，发现线索不会直接获得对应遗物。

### 收起界面，保留交互

隐藏 HUD 时仍可继续查看对话、获取提示，并访问设置，让画面更清爽。
