# Daily Build 更新

每次回到酒馆，都有一点新的变化。

这里按开发分支当日合入的内容整理，日期采用 UTC。目前提供每日开发更新记录，尚未提供独立 Release 下载包。

## 2026.09.12 · 听一首歌，找一个落脚点 {#day-2026-09-12}

### 人物走进故事

- **酒馆有了吟游诗人。** 经绯月介绍、与他相识后，可以围绕不同话题交谈；到了演出时段，他会在专属区域演奏，周围客人也会作出反应。
- **招呼更贴近当下。** 绯月会区分初次见面和再次来访，并根据营业时段与忙碌程度回应。
- **先选话题，再聊事情。** 日常问候与不同任务的谈话入口分开，方便选择此刻想聊的内容。
- **对白出现在角色身边。** 场景内的对白气泡配合可滚动的选项，让交谈留在酒馆之中；同时扩大了游戏画面的展示空间。

### 一张餐桌，一间阁楼

帮忙清理第一张餐桌、领取赠饮后，绯月会邀请你暂住楼上的临时客房。“一个落脚点”引导你上楼查看床铺。

床铺提供睡八小时或睡到次日 16:00 的选择。确认前可以看到醒来时间与生命消耗；这间临时客房免收房费，睡眠仍会消耗经过的时间。

### 交互更顺手

- 只要能找到商人并正常交谈，就能买卖商品；打烊后也可以交易。
- 靠近可交互的人物和物件时，会出现白色轮廓提示。
- 酒馆服务员可以使用多个柜台交接位置，减少单个位置被挡住时的停顿。

::: tip 体验新增剧情
已有时间线会保留开始时的剧情内容。想体验这批新对白与任务，请开启新的时间线。
:::

## 2026.09.11 · 时间开始流动，遗物有了位置 {#day-2026-09-11}

### 酒馆有自己的节奏

世界时间开始按段推进，生命余时随时间结算；普通交谈期间，人物活动与世界时钟也会继续。主动等待让你更快抵达下一个时刻，后台与闲置暂停则保留离开时的进度。

### 给遗物留一个位置

- 普通背包与遗物收藏分开，分别通过 `1`、`2` 或界面入口打开。
- 收藏使用 31 个固定格位，获得顺序不会改变遗物的位置。
- 尚未获得的遗物也能查看已经发现的线索与来源；获得后揭示名称、故事和效果说明。
- 线索与遗物分别收集，发现线索不会直接获得对应遗物。

### 收起界面，保留交互

隐藏 HUD 时仍可继续查看对话、获取提示，并访问设置，让画面更清爽。
