# Daily Build 更新

按开发分支当日合入的内容整理，日期采用 UTC。以下为每日开发更新记录，尚未提供独立 Release 下载包。各日期描述当时的变更，当前规则见[系统一览](/systems/)。

## 2026.09.15 {#day-2026-09-15}

| 类型 | 更新 | 说明 |
| --- | --- | --- |
| 功能 | 室外探索 | 酒馆与林间营地双向通行，沿用同一时间线的时间、存档与回放流程。室外提供探索与通行，尚未接入人物活动。 |
| 功能 | 帐篷入口 | 进入左侧帐篷门洞返回酒馆；经过或停留在门前不触发场景切换。 |
| 架构 | NPC 身份统一 | 人物在活动结束后保留身份；动态顾客离店后保留记录，后续去向与再次来访尚未实现。 |
| 架构 | NPC 能力与活动归属 | 商店、作息、服务、演出和教学配置归属 NPC；座位绑定进入活动状态，订单等共享进度由对应系统维护。 |
| 架构 | 地图 JSON 配置 | 地形、碰撞、图层和环境动画使用 JSON 配置；场景负责摆放与连接，剧本负责对白、条件与任务。 |
| 维护 | 格式检查与文档 | 增加 Prettier CI，整理[世界架构说明](/architecture/world-model-2026-09-15)。 |

**存档提示**：体验室外场景与新的 NPC 配置需从存档 0 开启新时间线；旧时间线继续使用原内容与规则，旧存档仍可恢复和回放。

## 2026.09.14 {#day-2026-09-14}

| 类型 | 更新 | 说明 |
| --- | --- | --- |
| 功能 | 吉他指导练习 | 正式结识诗人后，可在演出结束且他有空闲时借琴学习；结束后归还，学习进度保留，可再次复习。 |
| 功能 | 练习操作与判定 | W、A、S 对应高、中、低音区，提示经过判定线时按键。按错影响短句首音，漏按使该句留白，伴奏继续；跟上足够短句即可完成练习。 |
| 功能 | 曲谱与音频 | 《Song Of Growth》使用木吉他音色；老师示范、玩家练习和首演共用编配，包含和弦伴奏及力度变化。 |
| 功能 | 示范、重试与跳过 | E 开始练习，Esc 结束；准备时可听示范，曲终可重试。首演增加“跳过”入口，接续演出后剧情。 |
| 功能 | 学琴任务 | “弦上的第一步”记录借琴与练习过程；诗人留到 21:00 再开始离场。 |
| 功能 | NPC 每日作息 | 绯月 10:00 返回、次日 00:30 离场；莉奈 13:00 返回、23:00 离场；诗人 18:30 返回、21:00 离场。离场时结束交谈，莉奈先完成已接待客人的服务；路线受阻可能延迟到达。 |
| 功能 | 等待与睡眠滑条 | 统一选择 1–24 小时，等待默认 1 小时、睡眠默认 8 小时；确认前显示结束时刻、余时消耗和剩余余额。 |
| 功能 | 阶段任务回顾 | 任务面板逐步展示背景、目标与经历；帮工、结识诗人、客房和学琴任务完成后保留总结。 |
| 功能 | 任务进度通知 | 新任务、进度变化和完成时，在左侧显示提示。 |
| 功能 | 对话键盘导航 | W/S 或 ↑/↓ 选择，E 确认，Esc 离开；选项高亮并自动滚入视野，打开对话或切换话题后默认选中首项。保留鼠标与 Tab/Enter 操作。 |

**存档提示**：新的作息、课程和任务内容需开启新时间线；已有时间线保留开始时的剧情内容。

## 2026.09.12 {#day-2026-09-12}

| 类型 | 更新 | 说明 |
| --- | --- | --- |
| 功能 | 吟游诗人 | 经绯月介绍并相识后，可围绕不同话题交谈；演出时在专属区域演奏，周围客人作出反应。 |
| 功能 | 条件对白与话题 | 绯月区分初次见面与再次来访，并按营业时段和忙碌程度回应；日常问候与任务话题分别提供入口。 |
| 功能 | 场景对白气泡 | 对白与可滚动选项显示在角色身边，同时扩大游戏画面展示空间。 |
| 功能 | 临时客房任务 | 清理第一张餐桌并领取赠饮后，绯月邀请玩家暂住楼上；“一个落脚点”引导上楼查看床铺。 |
| 功能 | 客房睡眠 | 当时提供睡 8 小时或睡到次日 16:00 的选项，确认前显示醒来时间与生命消耗；客房免房费，睡眠消耗经过的时间。9月14日已改为时长滑条。 |
| 修复 | 商人交易条件 | 商人可达且可正常交谈时即可交易，打烊后也可买卖。 |
| 功能 | 交互轮廓提示 | 靠近可交互人物与物件时显示白色轮廓。 |
| 功能 | 多柜台服务站位 | 服务员可使用多个柜台交接位置，减少单个位置受阻时的停顿。 |

**存档提示**：体验新增对白与任务需开启新时间线；已有时间线保留原剧情内容。
