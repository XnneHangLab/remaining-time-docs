## 一致性与使用边界

背景、物件、帧图集与坐标均来自同一提交。拼装预览包含地图 art 和 scene 中的可交互家具，按游戏的坐标、偏移、锚点与图层排序绘制；定位函数直接取自该提交的 `prototype/assets.ts`，导出记录还保存了每张图片的 SHA-256。

这张图用于比较**初始房间布局**。青色传送触发格默认显示，可关闭；格子直接取自同一提交的 portalTiles，缺省时使用实体 position 单格，不依赖透明贴图。展开坐标列表可读取入口 ID、格子坐标和目的地；此覆盖层不判断剧情通行条件，也不表示完整碰撞或可达性检查。NPC 默认隐藏，可开启初始站姿；玩家、存档中的移动与剧情结果、交互高亮不在本图内。文档采用 Canvas 2D，游戏采用 PixiJS，因此不能将布局规则一致等同于所有浏览器、缩放比例下像素完全一致。尚未做逐房间浏览器视觉验收。

站点构建与访问只使用本仓库的静态快照，不请求私有游戏仓库、不携带访问令牌。后续布局变动需重新导出并审核快照，导出方法见仓库 README。
