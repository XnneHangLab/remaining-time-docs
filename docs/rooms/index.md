## 本轮快照的实际情况

本页固定为游戏合并提交 `7f3916798e0e6deba625a80c87fa1f9352796a49`（Noel 私人厅家具 #128）。它是一个明确的版本基准，**不代表游戏远端的实时最新状态**。

- **21 间使用黑框版（约 81%）**：本轮快照包含已接入的 Noel 私人厅床区、工作区与会客区（9 个独立物件），以及花园维护层密室、余烬后台与账房等房间的家具。沙发在图层中独立，不等于已配置坐下或剧情交互。
- **5 间使用普通版**：下层回廊、检修捷径、旧洗衣管道、高层天井和余烬休息间；屋顶一天花园现已使用黑框版。是否启用黑框以运行地图为准，不以本地候选是否存在来判断。
- 下层回廊当前有 **3 件独立物件**；其他房间的变化也随同一个游戏提交导出。黑框覆盖率只统计运行背景，不代表游戏内通行、交互或存档恢复已完成验收。
- 每间房的原始完整 PNG 和普通空背景均已收录。具体房间名称、版本、独立物件数量与数据差异，以以上自动导出的表格为准。

## 一致性与使用边界

背景、物件、帧图集与坐标均来自同一提交。拼装预览包含地图 art 和 scene 中的可交互家具，按游戏的坐标、偏移、锚点与图层排序绘制；定位函数直接取自该提交的 `prototype/assets.ts`，导出记录还保存了每张图片的 SHA-256。

这张图用于比较**初始房间布局**。NPC 默认隐藏，可开启初始站姿；玩家、存档中的移动与剧情结果、交互高亮、碰撞调试覆盖层不在本图内。文档采用 Canvas 2D，游戏采用 PixiJS，因此不能将布局规则一致等同于所有浏览器、缩放比例下像素完全一致。尚未做逐房间浏览器视觉验收。

站点构建与访问只使用本仓库的静态快照，不请求私有游戏仓库、不携带访问令牌。后续布局变动需重新导出并审核快照，导出方法见仓库 README。
